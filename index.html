🔐 Nexus Vault

Client-Side Encrypted Cloud Storage with Secure File Sharing & Access Revocation

A full-stack cloud security application that encrypts files before storage and provides controlled, cryptographically protected file sharing.

🌐 Overview

Nexus Vault is a secure cloud storage platform designed to address confidentiality and access-control challenges associated with storing sensitive files on cloud infrastructure.

The core principle is: Encrypt the data before it reaches the storage server.

Nexus Vault uses a hybrid cryptographic architecture in which AES is used for efficient file encryption while RSA is used to protect the corresponding encryption key. The platform combines cryptographic protection with authenticated access, secure file sharing, and access revocation.

🎯 Project Objectives

  • 🔐 Protect files before they are stored on the server.
  • 🔑 Implement secure cryptographic key management.
  • 📁 Provide authenticated cloud file storage.
  • 🤝 Enable secure file sharing between registered users.
  • 🚫 Provide access revocation for shared files.
  • 👤 Prevent unauthorized access through authentication and authorization.
  • 🧩 Demonstrate practical application of hybrid cryptography.
  • ☁️ Provide a foundation for future cloud deployment.

🚫 Access Revocation

The owner can revoke application-level access previously granted to another user. Important: Revocation prevents future access through the application. It cannot remove a plaintext copy that a recipient has already downloaded.

🚀 Installation

Prerequisites

  • Node.js & npm
  • MongoDB / MongoDB Atlas
  • Git

Clone the Repository

git clone https://github.com/YOUR_USERNAME/nexus-vault.git
cd nexus-vault

Backend Setup

npm install

Create a .env file in the root directory:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

Start the backend server:

npm run dev

Backend runs on: http://localhost:5000

Frontend Setup

Open another terminal:

cd frontend
npm install
npm start

Frontend runs on: http://localhost:3000

⚠️ Current Limitations

Nexus Vault is an academic/project implementation and should undergo additional hardening before production deployment.

  • Private-key protection relies on client-side handling.
  • Loss of the private key can prevent file recovery.
  • Production deployment requires HTTPS.
  • Production systems require secure secret management.
  • Revocation cannot invalidate files already downloaded by a recipient.
  • Large-scale cloud storage requires dedicated object-storage infrastructure.
